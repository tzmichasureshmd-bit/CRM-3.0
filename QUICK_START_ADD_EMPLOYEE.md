# 🚀 Quick Start: Add Your First Team Member

## Option 1: Direct Add (Fastest) ⚡

```
1. Login: https://crm3.tzmicha.com
2. Click: Settings (bottom left) → Team Members
3. Click: "Add Employee" button (blue, top right)
4. Fill in form:
   ┌─────────────────────────────────┐
   │ Name: Ramesh Kumar              │
   │ Email: ramesh@company.com       │
   │ Role: [Support ▼]               │
   │                                 │
   │ Channel Access:                 │
   │ ✅ 💬 WhatsApp                  │
   │ ✅ ✉️  Email                    │
   │ ☐ 📸 Instagram                  │
   │ ☐ 📘 Facebook                   │
   │ ☐ ✈️  Telegram                  │
   │                                 │
   │ Permissions:                    │
   │ ✅ View Conversations           │
   │ ✅ Reply to Messages            │
   │ ☐ Manage Contacts               │
   │ ☐ Assign Conversations          │
   │ ☐ Access Reports                │
   │                                 │
   │ [Add Employee]                  │
   └─────────────────────────────────┘
5. Click: "Add Employee"
6. ✅ Done! Employee can login now with email
```

**Time:** 2 minutes  
**Result:** Instant access

---

## Option 2: Send Invitation Link 📧

```
1. Login: https://crm3.tzmicha.com
2. Click: Settings → Invitations & Requests
3. Tab: "Sent Invitations"
4. Fill in:
   ┌─────────────────────────────────┐
   │ Email: employee@company.com     │
   │ Role: [Agent ▼]                 │
   │ [Send Invite]                   │
   └─────────────────────────────────┘
5. Click: "Send Invite"
6. Copy invitation link that appears:
   https://crm3.tzmicha.com/invite?token=ABC123...
7. Share link via:
   • WhatsApp
   • Email
   • SMS
   • Telegram
8. Employee opens link
9. Employee accepts invitation
10. ✅ Done! Employee joins your company
```

**Time:** 3 minutes  
**Result:** Secure token-based invitation  
**Expires:** 7 days

---

## Option 3: Join Request (Employee-Initiated) 🙋

```
1. Give employee your Company ID
   (Find it in: Settings → Company Profile)

2. Employee goes to:
   https://crm3.tzmicha.com/settings/team-requests

3. Employee fills in:
   ┌─────────────────────────────────┐
   │ Company ID: abc123-xyz-...      │
   │ Message: I'd like to join...    │
   │ [Send Request]                  │
   └─────────────────────────────────┘

4. You receive notification

5. You go to: Settings → Invitations & Requests
   Tab: "Join Requests" → "Incoming Requests"

6. You see request:
   ┌─────────────────────────────────┐
   │ Ramesh Kumar                    │
   │ ramesh@company.com              │
   │ Message: I'd like to join...    │
   │ [✓ Approve] [✕ Reject]          │
   └─────────────────────────────────┘

7. Click: "Approve"
8. ✅ Done! Employee added as Agent
```

**Time:** 5 minutes  
**Result:** Employee-initiated, admin-approved

## 🔧 Manage Employees

### **Edit Role:**
```
1. Go to: Team Members
2. Find employee
3. Click: ✏️ (Edit icon)
4. Select new role
5. Click: ✓
```

### **Deactivate:**
```
1. Go to: Team Members
2. Find employee
3. Click: ✕ (Deactivate icon)
4. Status changes to "Inactive"
5. Employee logged out immediately
```

### **Reactivate:**
```
1. Go to: Team Members
2. Find inactive employee
3. Click: ✓ (Reactivate icon)
4. Status changes to "Active"
5. Employee can login again
```

### **Delete:**
```
1. Go to: Team Members
2. Find employee
3. Click: 🗑️ (Trash icon)
4. Confirm deletion
5. Employee permanently removed
```
